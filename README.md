# Netflix SQL Database

## 📖 Description
This project is a relational SQL database designed for a Netflix-style streaming platform. It manages users, subscription plans, movies, TV shows, genres, watch history, ratings, and streaming-related data.

The project demonstrates SQL database design, normalization, table relationships, and data integrity using MySQL.

## ✨ Features
- User Management
- Subscription Plans
- Movies & TV Shows
- Genres
- Watch History
- Ratings & Reviews
- Content Management
- Relational Database Design

## 🛠️ Technologies Used
- SQL
- MySQL

## 🚀 Getting Started

### Prerequisites
- MySQL Server
- MySQL Workbench (or any SQL client)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Netflix-SQL-Database.git
   ```

2. Open MySQL Workbench.

3. Import the SQL file:
   ```
   netflix full.sql
   ```

4. Execute the script to create the database and tables.
